# Yiwei You — Research & Practice

Personal academic portfolio. Static HTML, CSS and JavaScript; no build step required.

## GitHub Pages

Publish from the `main` branch, repository root (`/`). All asset paths are relative, supporting both user and project sites. `.nojekyll` preserves the static files as written.

## Updating

Edit `index.html`, stylesheets, or JavaScript and commit to `main`. GitHub Pages publishes the update automatically after branch publishing is enabled.
